ESP32 IoT Dashboard • Responsive Mobile-First Controller

ติดตั้งโปรแกรม & ผังการต่อสาย ESP32

แผนผังต่อสายขาบอร์ด และระบบ Flash Firmware อัตโนมัติ

⚡ 1. รีเลย์ 4 ช่อง (Relay Module 4CH - Active LOW)
GPIO 16 → Relay IN 1 (ไฟ Grow Light)
GPIO 17 → Relay IN 2 (ปั๊ม Oxygen)
GPIO 18 → Relay IN 3 (อากาศออก Exhaust)
GPIO 19 → Relay IN 4 (ปลั๊กเสริม Aux)
5V / VCC → VCC ของบอร์ดรีเลย์
GND → GND (กราวด์ร่วม)
🌡️ 2. เซนเซอร์วัดอุณหภูมิและความชื้น (DHT11 / DHT22)
GPIO 4 → ขา DATA / OUT ของเซนเซอร์ DHT
3.3V → VCC ของเซนเซอร์
GND → GND
🎨 3. เซนเซอร์ตรวจจับสีจริง (TCS34725 I2C)
GPIO 21 → ขา SDA (I2C Data)
GPIO 22 → ขา SCL (I2C Clock)
GPIO 23 → ขา LED (สวิตช์เปิด-ปิดไฟส่องสี)
3.3V → VIN / 3V3
GND → GND

🚀 ติดตั้งเฟิร์มแวร์ลงบอร์ด ESP32 ผ่านเบราว์เซอร์

ระบบจะเชื่อมต่อสาย USB, เลือกรุ่นบอร์ด, ล้าง Flash และเบิร์นโปรแกรมพร้อมแสดงแถบโหลด 0% → 100% ให้ทันที

เบราว์เซอร์นี้ไม่รองรับ WebSerial กรุณาใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ กรุณาอนุญาตการเข้าถึงพอร์ต Serial เพื่อเบิร์นบอร์ด
1 เสียบสาย USB ระหว่างคอมกับบอร์ด ESP32
2 กดปุ่ม Install แล้วเลือกพอร์ต COM ของบอร์ด (เช่น USB-SERIAL CH340 / CP210x)
3 ระบบจะแสดงแถบ Progress Bar กำลังโหลดกี่ % จนครบ 100% พร้อมใช้งานทันที
